# Quickstart: self-host

<Prereqs>
- A Linux server with Docker.
- Port 8080 (UI) reachable by your team, port 4318 (OTLP/HTTP) reachable by your services.
</Prereqs>

<Steps>

<Step title="Run the container">

Signals and settings live in the `/data` volume. Keep it across upgrades.

```shell
docker run -d --name cometrace \
  -p 8080:8080 -p 4318:4318 \
  -v cometrace:/data \
  [IMAGE]/cometrace:0.0.0
```

</Step>

<Step title="Copy the setup token">

On first boot the server prints a one-time setup token in its log.

```shell
docker logs cometrace 2>&1 | grep "setup token"
```

```text
setup token: [EXAMPLE TOKEN]
```

<Callout type="warning">
There is no default password. The token works once. If you lose it before setup, restart the container to print a new one.
</Callout>

</Step>

<Step title="Create the first admin">

Open `http://your-server:8080`, paste the token, then choose an email and a password of at least 12 characters. You land in your workspace as its admin.

</Step>

<Step title="Create a project and an ingest key">

In Settings › Projects, create a project for the service you want to instrument. Then in Settings › Ingest keys, issue a key for it. Ingest keys start with `cmt_ik_`.

<Callout type="note">
The key is shown once. Store it in your secret manager before closing the dialog; afterwards only its prefix is visible.
</Callout>

</Step>

<Step title="Send a span">

Any OpenTelemetry SDK or Collector works; there is no Cometrace SDK.

<CodeTabs group="send-a-span">

<CodeTab label="SDK">

```shell
export OTEL_EXPORTER_OTLP_ENDPOINT=http://your-server:4318
export OTEL_EXPORTER_OTLP_HEADERS="authorization=Bearer cmt_ik_…"
export OTEL_SERVICE_NAME=checkout
```

</CodeTab>

<CodeTab label="Collector">

```yaml
exporters:
  otlphttp/cometrace:
    endpoint: http://your-server:4318
    headers:
      authorization: Bearer cmt_ik_…

service:
  pipelines:
    traces:
      exporters: [otlphttp/cometrace]
    logs:
      exporters: [otlphttp/cometrace]
    metrics:
      exporters: [otlphttp/cometrace]
```

</CodeTab>

<CodeTab label="curl">

```shell
curl -X POST http://your-server:4318/v1/traces \
  -H "content-type: application/json" \
  -H "authorization: Bearer cmt_ik_…" \
  --data @span.json
```

</CodeTab>

</CodeTabs>

Restart your service with these variables. Logs and metrics use the same endpoint and key.

</Step>

<Step title="Check it arrived">

Open Traces with the range set to Last 15 m. If nothing shows up:

| Symptom | Fix |
| --- | --- |
| 401 from the exporter | The key is wrong or revoked. Issue a new one in Settings › Ingest keys. |
| 404 from the exporter | The endpoint has a path. Set the base URL only; SDKs add `/v1/traces`. |
| No error, no data | Check the project selector in the top bar, then widen the time range. |

</Step>

</Steps>
