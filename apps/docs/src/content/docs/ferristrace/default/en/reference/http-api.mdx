# HTTP API reference

All HTTP API routes are served on the main HTTP port (`4318` by default, alongside OTLP/HTTP `/v1/*` and the web application).

<Callout type="note" title="Timestamps and window units">
Query parameters `from` and `to` on `/api/orgs/{org}/*` routes are **Unix epoch milliseconds** (`u64`), except `POST /api/v1/dashboards/query` which takes `from_ns` and `to_ns` in **Unix epoch nanoseconds**.
</Callout>

**Auth legend:**
- **`Public`** — No `Authorization` header required.
- **`Read`** — Accepts a signed-in member OIDC token, a `read`-scoped `ft_live_` API key, or an AI agent JWT with `telemetry:read`.
- **`Member`** — Requires a signed-in organisation member OIDC token (`member`, `admin`, or `owner`).
- **`Admin`** — Requires a signed-in `admin` or `owner` OIDC token (some org-level actions require `owner`).

## Health, auth & public status

| Method | Path | Auth | Description |
| --- | --- | --- | --- |
| `GET` | `/health` | `Public` | Liveness probe (`200 OK`, body `ok`) |
| `GET` | `/auth/methods` | `Public` | Returns `{ "oidc": bool, "issuer": string\|null, "client_id": string\|null }` |
| `GET` | `/api/me` | `Member` | Current account profile, avatar URL, and organisation memberships |
| `GET` | `/api/pages/ack?token=...` | `Public` | One-click HMAC-signed on-call page acknowledgement (`24h` validity) |
| `GET` | `/api/status/{slug}` | `Public` | Public status page JSON (`Access-Control-Allow-Origin: *`) |
| `POST` | `/api/status/{slug}/subscribe` | `Public` | Subscribe an email address to public status updates (`202 Accepted`) |

## Traces, spans & services

| Method | Path | Auth | Description |
| --- | --- | --- | --- |
| `GET` | `/api/orgs/{org}/traces` | `Read` | List trace summaries (`from`, `to`, `project`, `service`, `name`, `errors`, `at_least_us`, `order`, `limit`, K8s placement) |
| `POST` | `/api/orgs/{org}/traces/search` | `Read` | Search traces with a structured query AST (`ExprBody`) |
| `POST` | `/api/orgs/{org}/traces/facets` | `Read` | Compute facet value counts across matching spans |
| `GET` | `/api/orgs/{org}/traces/{trace_id}` | `Read` | Fetch full trace waterfall (`spans`, `attributes`, `events`) |
| `POST` | `/api/orgs/{org}/spans/search` | `Read` | Search individual spans (`started` or `duration` order) |
| `POST` | `/api/orgs/{org}/spans/series` | `Read` | Time-bucketed span aggregations |
| `POST` | `/api/orgs/{org}/spans/table` | `Read` | Grouped span aggregation table |
| `GET` | `/api/orgs/{org}/attributes` | `Read` | List observed span attribute keys |
| `GET` | `/api/orgs/{org}/attributes/{key}/values` | `Read` | List observed values for a span attribute key |
| `GET` | `/api/orgs/{org}/services` | `Read` | List services with request count, error rate, and latency percentiles |
| `GET` | `/api/orgs/{org}/services/dependencies` | `Read` | Directed service-to-service call graph edges |
| `GET` | `/api/orgs/{org}/services/{service}/operations` | `Read` | Per-operation RED metrics for one service |
| `GET` | `/api/orgs/{org}/services/{service}/series` | `Read` | Request, error, and latency time series for one service |
| `GET` | `/api/orgs/{org}/services/{name}/placement` | `Read` | Project and environments observed for a service |
| `GET` | `/api/orgs/{org}/series` | `Read` | Organisation-wide request/error/latency time series |

## Backend domain views, releases, issues & LLM

| Method | Path | Auth | Description |
| --- | --- | --- | --- |
| `GET` | `/api/orgs/{org}/requests` & `/requests/series` | `Read` | HTTP server route breakdown (`2xx`/`4xx`/`5xx`, latency, time share) |
| `GET` | `/api/orgs/{org}/jobs` & `/jobs/series` | `Read` | Queue/consumer job throughput, errors, and duration |
| `GET` | `/api/orgs/{org}/caches` & `/caches/series` | `Read` | Redis/Memcached/Valkey call volume, latency, masked key patterns, and `cache.hit` rate |
| `GET` | `/api/orgs/{org}/statements`, `/statements/series`, `/statements/fanouts` | `Read` | Normalised SQL/DB queries and N+1 per-trace fanout detection |
| `GET` | `/api/orgs/{org}/releases`, `/releases/{service}/{version}`, `/deploys` | `Read` | Detected `service.version` releases and deploy markers |
| `GET` | `/api/orgs/{org}/issues` | `Read` | Grouped exception issues in window (`project`, `service`, `text`, `limit`) |
| `GET` | `/api/orgs/{org}/issues/{fingerprint}` & `.../occurrences` | `Read` | Issue detail and recent occurrences with `trace_id` links |
| `PATCH` | `/api/orgs/{org}/issues/{fingerprint}` | `Member` | Update issue status (`unresolved`, `resolved`, `ignored`) or `owner` |
| `GET` | `/api/orgs/{org}/llm/calls` & `/llm/unpriced` | `Read` | Query GenAI calls/costs and list models missing a price entry |
| `GET` / `POST` | `/api/orgs/{org}/llm/prices` | `Read` / `Admin` | List or add effective-dated model token rates (micro-dollars per 1M tokens) |
